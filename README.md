# WinEase

极简 Windows 工具箱：清理、空间管理、应用管理与常用系统设置。

未来定位与功能取舍见 [产品方向](docs/product-direction.md)。

品牌原图与图标生成方式见 [品牌资源](docs/branding/README.md)。

## v3.5.0

- 默认窗口 1280 × 820，根据显示器工作区与 DPI 自动缩小；组件中心三列布局。
- 内置鸿蒙字体，字号与密度按窗口自动适配；进程、启动项和弹窗显示应用图标，Snipaste 与其他组件统一排版。
- 整合网络急救箱：检查、按问题修复、自动备份和复检；专项操作及还原默认折叠，详见 [整合与调研](docs/network-integration.md)。
- 首页为「一键检查 → 集中查看结果 → 确认一键优化」，同时检查清理、空间、体检、网络与开机项。设备信息移至设置，赞助位于设置 → 关于。
- 删除 AI、本地模型、Qclaw、Ollama、首页截图和最近结果。
- Tauri 2.12.1 + Rust + WebView2 Evergreen，React 19.3 / Vite 8。

## 功能

| 页面 | 功能 |
| --- | --- |
| 首页 | 一键检查五类项目、集中展示建议与文件、确认后一键执行并展示实际结果 |
| 清理 | 临时文件、日志、图形、网页、应用、下载/构建缓存、崩溃报告；先扫描，再清理 |
| 空间管理 | 选择磁盘全盘统计、按面积显示占用图、文件夹下钻、文件大小排序、SHA-256 重复文件、选择个人文件移入回收站 |
| 应用管理 | 当前会话进程、应用窗口、可恢复的用户 Run 启动项、深度卸载组件、弹窗规则 |
| 系统工具 | 隐藏文件（自动刷新资源管理器）、单一电源计划选择器、任务栏修复、默认浏览器与默认应用、统一系统组件/文件修复 |
| 电脑体检 | 内存、磁盘、待重启/更新暂停、防护与病毒库、活动防火墙、异常设备及近期系统错误 |
| 网络修复 | 网卡、IPv4/IPv6、DNS、直连/代理、TUN/路由、Hosts、WinHTTP 诊断；按证据修复、备份还原、脱敏报告；下载/上传 Mbps 测速、延迟和抖动 |
| 组件 | Everything、Snipaste、BCUninstaller 等组件的安装、打开、修复、更新与卸载 |
| 设置 | 设备信息与日志、紧凑组件/许可证列表、老板键、关于与赞助 |

## 操作边界

- 首页检查不修改系统；一键优化需要查看结果后确认，只执行已选项目。个人大文件默认不选，安全配置/重启等需判断的问题保留处理入口。检查与建议规则见 [一键检查与优化](docs/one-click-optimization.md)。
- 清理仅扫描固定白名单。网页/应用/图形缓存保留 24 小时，其他类别保留 7 天，跳过链接和应用占用的文件。确认后直接删除，执行前再次检查大小、修改时间和路径。详见 [清理与空间分析](docs/cleanup-and-storage.md)。
- 空间分析默认系统盘，系统/程序文件仅供统计不可删除。扫描最多 200,000 个条目、180 秒，文件列表最多展示最大的 2000 个，超限显示部分结果。占用图按逻辑大小统计；重复文件每组必须保留一份，移动前重新校验内容。
- 个人文件使用 Windows 回收站 API 并强制回收，不回退为永久删除；回收站不支持的位置会报告失败。回收站清空后才释放空间。
- 启动项停用保留完整原始注册表值和类型，可恢复；Windows 自己停用的项、所有用户项与其他启动来源在 Windows 设置管理。
- 弹窗拦截由用户逐项添加，按应用路径及完整窗口标题匹配，工具箱运行时有效。发送正常关闭请求，不保证应用接受关闭；动态标题需要单独规则。系统和受保护窗口不可添加。
- 默认浏览器和默认应用通过 Windows 官方设置页面完成，软件不绕过系统关联确认。
- 任务栏修复会重启当前会话的 Explorer，文件夹窗口可能关闭。电源计划读取实际状态，不支持高性能计划的设备禁用对应选项。
- 深度卸载使用 [BCUninstaller](https://www.bcuninstaller.com/)，残留选择和确认由其完成。组件卸载成功后只清除本工具箱的组件记录，不递归删除第三方数据目录。
- 网络修复先检查，再由后端生成修复计划；执行前重新核实、备份，执行后复检。保留可用代理/TUN、PAC、静态 IP 和组织策略。危险的网卡/网络栈/防火墙重置需单独确认，不保证能通过快照完整回滚。
- 带宽测速需主动点击，沿用 Windows 系统代理/PAC/TUN，使用 Cloudflare 服务，分别显示下载/上传 Mbps、HTTP 延迟与抖动。每次请求最多 144 MiB 生成数据（不含协议开销），可停止；不上传用户文件或系统配置。结果代表到测速服务器的当前路径，并非运营商套餐速率。
- 文件显示设置首次修改前备份原值，修改/还原后自动重启当前会话资源管理器。统一系统修复经管理员授权运行 DISM RestoreHealth 与 SFC，不自动重启整台电脑。
- 老板键为模拟更新界面，不执行 Windows 更新。应用内 Ctrl + Alt + B 切换、Esc 退出，设置页可直接进入。

## 开发

```powershell
npm ci
npm run tauri dev
npm run build
cargo test --manifest-path src-tauri/Cargo.toml --lib
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-network-safety.ps1
powershell -NoProfile -ExecutionPolicy Bypass -File scripts/test-network-speed.ps1
npm run tauri build -- --bundles nsis
```

环境：Windows 10/11、Node.js 22+、Rust MSVC 工具链、Visual Studio C++ Build Tools、WebView2。

设计与验证说明见 [优化审查](docs/optimization-review.md)。
