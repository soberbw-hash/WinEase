# 清理与空间分析改进

2026-10-03，按用户反馈扩展实际扫描范围，简化操作。

## 原因与调研

旧清理仅包含用户 Temp、少量图形和缩略图缓存，统一排除 7 天内文件。因此没有覆盖网页/应用缓存，不能称为完整深度清理。[Microsoft 存储与清理建议](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/free-up-drive-space-in-windows)区分临时/系统文件、大文件、应用；[BleachBit 官方清理文档](https://docs.bleachbit.org/)按应用定义清理目标。Cookie/登录数据和普通网页缓存不能视作同一种内容。

本版添加 Chrome、Edge、Brave、Vivaldi 各配置目录及 Firefox 的专用网页缓存；Code、Discord、Slack、Teams、Steam 的固定运行缓存；用户崩溃转储和 WER 报告；npm 内容缓存、pip 缓存和 NuGet v3 元数据缓存。仅扫描明确可再生成的子目录，不按“cache”关键词遍历整个用户目录。临时文件、错误报告和下载/构建缓存保留 7 天；网页/应用/图形缓存保留 24 小时。不会自动关闭用户应用，正在使用的文件通过独占读取保护跳过。执行前再次校验修改时间、大小和路径，禁止链接穿透。

不清理 Cookie、浏览记录、密码库、IndexedDB、本地存储、聊天附件、模型、安装中的依赖、Downloads 或个人文档。Windows.old、组件存储、更新数据库、驱动仓库等交给 Windows 自身维护，不能直接递归删目录来凑清理量。缓存会重新生成，扫描结果是候选文件字节总量，不承诺全部都能删除或等同磁盘实际分配空间。

只读抽查发现旧扫描漏掉约 120.71 MB 网页缓存、9 MB 应用运行缓存和 1.52 GB 下载/构建缓存；抽查没有删除文件。这是当前机器的一次观察，不能保证每台机器均存在大量垃圾。

## 空间图与磁盘选择

不再要求输入路径：默认 C 盘，可以切换已挂载磁盘。扫描所有可读取的普通文件，系统和应用文件参与统计但不可选择删除；不读云占位内容、不穿透重解析点。重复文件只校验可删除的个人文件，并要求每组留一个内容相同的文件。

文件夹逐层累加文件逻辑大小，面积按同层字节量比例布局。可进入文件夹、返回上级或根目录；未展示的文件合并为“其他文件”，仍计入面积。列表最多显示最大的 2000 个文件，占用图提供最多 10000 个文件夹节点，扫描上限为 200000 项或 180 秒，达到上限明确显示部分结果。并非完整 MFT 审计，也不以逻辑大小冒充物理占用；硬链接可能重复计数。

## 设置与维护

文件扩展名/隐藏文件修改或还原后自动重启当前会话资源管理器，验证其重新启动；设置仍保留原值备份。文件夹窗口可能关闭，桌面和任务栏会短暂刷新。生产设置测试不重启用户实际资源管理器。

删除快速检查、深度扫描、驱动备份的重复/失效入口，统一为“系统修复 → 检查并修复”。内置固定助手经 UAC 授权，按 [Microsoft 推荐顺序](https://support.microsoft.com/en-au/windows/experience/backup-recovery/using-system-file-checker-in-windows)运行 DISM RestoreHealth 再运行 SFC；前一步失败停止后一步，保留本机记录与退出码。这个流程修复系统组件，不清理垃圾。不自动重启整台电脑，保留保存工作机会；当前账户不能借另一管理员身份修改用户配置。

隔离测试覆盖年龄差异、占用文件保护、扫描后变化、目录边界、扩展路径、系统文件只读、小文件和文件夹累计、DISM 失败顺序及重启结果。真实 UAC 修复与资源管理器重新启动需要 Windows 测试机验证，不能用隔离测试替代。

## 参考电脑管家的交互改进

本轮参考用户截图的操作逻辑，保持 WinEase 的界面风格：

- 清理结果拆成推荐系统清理、推荐应用清理和其他可选项目。按精确扫描根目录分组，每项能展开分页查看文件名、完整路径与大小，或打开所在目录；单页 100 条，清理范围仍由扫描令牌约束。下载/构建缓存、着色器缓存、错误报告默认不勾选，避免重建开销及丢失排障材料。
- 新增 Windows CBS/DISM/Panther 的旧日志（仅 `.log`）、Minidump 和系统 WER 报告，以及 ChatGPT/豆包/ToDesk 固定 Electron 缓存目录。只扫描存在的明确目录，不把其他应用数据当成缓存。无法读取的目录计入跳过数。
- Windows 更新与传递优化、回收站提供系统清理入口。微软为传递优化提供专门的 [Delete-DeliveryOptimizationCache](https://learn.microsoft.com/en-us/powershell/module/deliveryoptimization/delete-deliveryoptimizationcache) 操作，因此不直接删除它的内部目录；当前 WinEase 不承诺扫描并清理这部分容量。浏览记录/登录数据未加入清理。
- 开机项用直接开关表示当前状态；写入后刷新，失败保留原状态。当前仍只修改工具箱支持的用户 Run 项，Windows 已停用项、其他账户来源等显示只读开关，可进入系统启动应用设置管理，不假装能切换所有来源。
- 存储概览通过 GetDiskFreeSpaceExW 读取真实磁盘总容量与可用容量；分类和空间图按已读取文件统计。分类不是 Windows 原生分类器，使用路径归类，不把无法读取的数据推算成已扫描结果。
- 大文件提供文档/图片/压缩包/视频/音频/其他筛选、大小阈值、搜索、修改日期及紧凑表格。重复文件按内容校验后分组，智能勾选保留每组修改时间最新的一份，最多一次选中 2000 个副本。系统和应用目录、node_modules 与 .git 不参加重复文件清理；重复校验优先处理大文件，仍受扫描时间及数量上限限制。

隔离 Rust 测试验证根目录分组容量、只清理指定软件缓存、可选项目默认策略；浏览器模拟 IPC 验证推荐勾选、100 条明细分页、启动开关成功/失败、真实容量字段显示、类型/大小筛选、系统文件只读及重复组保留最新一份。没有清理个人文件或修改实际开机项。

## 软件合并与结果保留

清理树以软件为父项、缓存类型为子项，同一软件的多个配置目录合并显示，并汇总容量和文件数。每个类型可继续展开分页文件明细；勾选仍映射到原扫描根目录，部分勾选显示中间态。可定位的应用读取本机 EXE 图标，系统项目和无法定位的应用使用类型图标。

空间管理页面切换后保留扫描结果，并分别缓存磁盘及大文件/重复文件结果；扫描过程中离开页面不会中断。后端允许最多 6 个扫描令牌共存，各自有效 15 分钟，删除前仍逐项验证。

空间管理的磁盘统计与重复文件校验使用独立任务和取消标记，可以同时运行。存储概览和大文件共用同一次磁盘统计，三个页签在扫描中均可切换；完成、停止或失败只更新所属磁盘与任务的状态，不覆盖另一页面。文件列表按可见区域加载 Windows 文件关联图标，并保留扩展名标记；safetensors/gguf/onnx/pt/pth 标记为模型，Windows 没有关联图标时使用文件图形。只读取图标，不生成缩略图或打开文件内容。

本轮找到重复扫描返回空的直接原因：根目录文件保护规则也作用到了一级文件夹，误跳过用户目录。现仅保护根目录文件；用户目录优先遍历，系统、应用、node_modules 和 .git 不参加重复文件删除。达到时间或数量上限会保留已完成结果并明确标注，不能视作全盘完整扫描。

本机只读 C 盘集成检查：大文件返回 2000 条，耗时约 23 秒；重复文件返回 1 组、2 个文件，达到 180 秒上限，均属于部分结果，未删除文件。大文件数量不是整个卷的文件总数；重复检查在超大文件上仍有耗时瓶颈，后续需优化候选内容筛查，不能据此声称已完成全盘去重。浏览器模拟流程验证软件合并、子项勾选同步、文件明细分页、导航保留及扫描缓存。模拟软件图标不是实际品牌图标验证的替代。
