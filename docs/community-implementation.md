# 社区调优能力实现记录

日期：2026-10-12。沿用 WinEase 的功能定位与界面，不加入美化功能。

## 已实现

- **清理覆盖**：新增 Opera/GX、Epic、Cursor、VSCodium、Code Insiders、Notion、Obsidian、部分商店应用缓存，以及可选的 Yarn/Squirrel 缓存。只扫描精确缓存路径，保留近期文件、账号、浏览记录、聊天数据和个人内容。相同应用继续合并为二级项目，可查看文件。运行中的应用缓存跳过；进程读取失败时保守跳过应用缓存。
- **预装应用**：应用管理新增独立页面，显示名称、图标、版本、依赖和有边界的占用统计。12 个明确的可选包经过保护和依赖检查后才可移除；其他包默认不显示，可切换查看。仅移除当前用户，不影响系统预配和其他用户。移除前落盘安装信息，执行前重新验证包身份；支持尝试重新注册和商店重装。**卸载可能删除数据，安装信息不是数据备份。**
- **资源分析**：连续采样当前会话进程，按可执行文件路径合并 CPU、内存和进程数；读取最近开机与启动延迟事件。CPU 持续达到整机 15% 或内存达到 2 GiB 仅作为关注线索，不自动结束程序。无记录、无权限与缺少有效样本都明确处理。
- **安装与更新维护**：检查 BITS/Windows Update 启动方式、本地近期更新失败、待重启、商店/App Installer 包与 WinGet 可用性。按问题提供服务修复、原服务配置恢复、包重新注册、WinGet 官方源更新、商店缓存重置。服务修复只针对已禁用的两项服务，存在 Windows Update 组织策略时停止；不清空更新数据库、不删除定制源、不改代理。
- **功能偏好**：补充本地搜索、减少系统使用建议、关闭后台游戏录制；连同减少推广设置接入首页。备份首次原值、写入读回、需要时刷新资源管理器，支持恢复。手动截图和录制保留。搜索热点独立开关未加入，避免已知版本兼容问题。
- **统一检查**：首页九类结果并发呈现。清理等已有建议沿用；新增偏好、卸载和维护项目默认不勾选，选中后统一确认执行。后端只接受当前有效计划的项目 ID，执行前重新验证。资源分析、预装应用、维护任务各自管理状态；切页保留结果，离开弹窗页面暂停轮询。

## 验证与边界

- Rust 回归：81 项通过、12 项显式忽略。包括真实隔离目录缓存保护、依赖保护、持续采样聚合、七项隔离注册表配置备份与恢复、模拟服务配置的修复和恢复、非法服务记录拒绝。
- 浏览器模拟 IPC：34 组流程通过，涵盖系统设置、统一首页、先前自查与本轮 10 组新增管理流程。新增覆盖卸载确认/取消、恢复入口、跨页保留、任务独立、默认不勾选和 1280/760 宽度布局。
- 本机只读核验：成功读取 111 个当前用户应用包、资源分组、六项维护状态；九类首页检查完整返回。清理约 3.30 GB，大文件统计约 160 GB，文件扫描明确为部分统计。数值会随系统变化，不能当成清理收益。
- TypeScript/Vite 和原生签名安装包用于本地预览；正式发布与旧客户端升级另行验收。没有执行本机实际卸载、偏好修改或更新修复。隔离测试与模拟 IPC 不能替代不同设备、Windows 版本的真实操作验证。

应用读取与开机事件可能较慢；占用统计有限，不伪装为全部磁盘占用。恢复本地应用包依赖系统仍留存对应包；缺失时需商店重装。服务恢复是原启动方式及运行状态恢复，商店重装不保证原数据恢复。
