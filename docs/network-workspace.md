# 独立网络页面

2026-10-13。

左侧新增“网络”，分为检查与修复、网速测试、网站测试、IP 信息。独立检查仍使用现有网络诊断与证据修复后端，支持备份、复检和还原。首页一键检查保留网络问题与修复建议，不执行带宽测速、网站列表测试或 IP 查询；正常连接显示一项状态，详细联网探针留在网络页面。

带宽测速沿用现有主动点击的上下行 Mbps、HTTP 延迟、抖动和停止操作。网站测试固定为百度、哔哩哔哩、腾讯、GitHub、Google、YouTube，以系统代理/PAC 路径并发发送 HTTPS 请求，仅读取响应头，不下载网页正文，不使用登录 Cookies。每次请求限 8 秒，整体任务限 25 秒；响应时间包含 DNS、连接、代理和服务器响应，不等于 ICMP Ping。收到 403/429 等标记为站点限制，不当作断网；200 响应不是内容或登录功能验收。

IP 查询主动点击后通过 [ipwho.is](https://ipwhois.io/documentation) 获取本次连接出口的 IPv4 或 IPv6、服务商、组织、国家、地区、城市、ASN 和组织域名。只请求需要的字段，HTTPS 响应限 64 KiB。服务缺少的字段显示未提供；失败时尝试 Cloudflare trace，仅回退为出口 IP/国家代码，不编造城市、服务商或自治系统。免费归属服务目前允许商业使用，按客户端 IP 限每日 1000 次，没有可用性保证；不依赖 API 密钥，不在后台循环查询。使用代理时，数据可能属于代理出口；位置为数据库估计，不读取 GPS，也不声称能定位到区县或街道。

网站测试与 IP 查询分别锁定各自任务；一项进行中可切页或使用另一项。网络页首次打开才挂载，导航后保留诊断、测速、网站与 IP 状态；回首页不会重跑网络页检查。读取公网信息和网站测试的服务可见请求出口 IP，不发送个人文件或系统配置，不改变代理、DNS、网卡和路由。

系统工具的更新与安装修复卡片直接展开，去掉“按问题修复与恢复”折叠层；真正执行仍保留原确认与配置恢复机制。

验证：92 项 Rust 回归通过，16 项显式集成检查默认忽略。IP 解析覆盖缺失字段、失败响应、无效/本地地址与 IPv6 回退；真实只读 HTTPS 测试六站均返回 200，归属服务成功返回 IPv6 数据，未在日志输出公网地址。9 组浏览器模拟 IPC 检查覆盖独立菜单、主动操作、任务互不阻塞、跨页保留、站点限制与连接失败区分、宽窄布局及维护卡片直接可见。真实网络结果仅代表测试当时的当前连接，不保证其他运营商、代理或网站策略相同。
