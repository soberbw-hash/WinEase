# 一键检查与优化

2026-10-04：首页改为单一「一键检查」入口。点击只读取状态与扫描文件；五类结果集中到同一页面。完成后可查看文件、调整建议项，再通过「一键优化 → 确认并优化」执行。不会在打开软件或点击检查时清理文件、停用启动项或修改网络。

## 检查与建议

| 范围 | 展示与处理 |
| --- | --- |
| 深度清理 | 复用精确目录白名单、24 小时/7 天保留期限与占用保护；相同应用和缓存类型合并，明细每页 100 个。常规缓存默认建议，重建成本较高的缓存和错误报告需手动选择。 |
| 大文件与空间 | 自动遍历本地固定磁盘，列出 ≥100 MB 文件。旧下载目录安装包/压缩包给出确认用途的建议；其他个人大文件仅因体积列出，不默认选择。系统/应用文件只读。已归入缓存的文件不重复处理。 |
| 电脑体检 | 内存压力、磁盘可用空间、Defender/第三方防护提供程序、病毒库年龄、活动网络防火墙、更新暂停、待重启、异常设备及近 7 天异常关机/蓝屏/磁盘事件。读取失败标为未核实。需用户判断的问题进入对应系统或管理页面，不自动结束进程、改安全设置或重启电脑。 |
| 网络检测 | 复用直连/代理/DNS/网卡/路由检查与证据修复计划；可用代理/TUN 保留。无断网/重启影响的修复计划才默认建议；其他计划需手动选择。修复前重新核实、备份，修复后复检；仍有问题或复检失败明确显示未完整完成。 |
| 开机管理 | 检查用户 Run 与所有用户 Run 项。只对可编辑的当前用户、精确识别的游戏启动器默认建议关闭自启；聊天应用手动选择，网络/同步/驱动及未知软件保留。原注册表值及类型备份，可在开机管理恢复；已由 Windows 停用的项不会再修改。 |

内存 ≥85%、可用空间 <5 GiB 或同时 <20 GiB 且 <10%、Defender 病毒库 >7 天作为可解释的提示阈值，不生成虚构健康分。事件记录不能直接确定故障原因。磁盘错误建议先备份数据。

## 执行与状态

- 五类任务并发读取，完成一类就更新一类；个别失败不丢弃其他结果。首页保持挂载，切换到其他页面再返回时保留检查、选择和执行状态。
- 首页缓存/文件扫描拥有独立状态，其他页面扫描不覆盖其令牌。网络保留最多 8 个、10 分钟内的检测令牌。
- 文件统计每盘最多 90 秒，全盘合计最多 180 秒，复用每盘 200,000 条目/2000 最大文件边界；达到上限或读取失败明确显示部分统计。结果不是完整磁盘空间核算。
- 清理白名单目录共用 120 秒/500,000 条目检查预算，达到上限保留并展示部分清理项。合作式检查不能中断单个阻塞的文件系统调用。
- 检查计划自开始起 10 分钟有效。后端仅接受当前计划中的操作 ID、去重选择及明确确认，不接受页面提供的新路径或命令；执行时再次校验文件和启动项。检查有效不等于执行时文件仍然相同。
- 同一缓存扫描的多个类别一次合并执行，个人文件按磁盘令牌合并移入回收站；每项执行结果和实际释放量保留。文件变化、占用、无权限或回收失败不伪装成功。网络操作最后执行，减少断网对其他处理的影响。
- 缓存为直接删除；个人文件强制回收，不回退为永久删除。回收文件尚未清空回收站时不会释放实际磁盘空间。没有默认清空回收站、删除聊天记录、删除文档或重置网络栈。

## 依据

设计参考用户提供的微软电脑管家流程，保留 WinEase 视觉和交互。功能判断参考微软官方资料：

- [Windows 性能改善建议](https://support.microsoft.com/en-us/windows/experience/performance-optimization/tips-to-improve-pc-performance-in-windows)：围绕存储、开机应用和当前资源压力组织检查。
- [Storage Sense 管理空间](https://support.microsoft.com/en-us/windows/experience/storage-filemanagement/manage-drive-space-with-storage-sense)：临时文件与个人下载文件需区别处理。
- [Get-MpComputerStatus](https://learn.microsoft.com/powershell/module/defender/get-mpcomputerstatus)：读取实际防护状态和病毒库年龄。
- [事件 41 的诊断范围](https://learn.microsoft.com/en-us/troubleshoot/windows-client/performance/event-id-41-restart)：异常关机记录仅作为排查线索，不直接判定硬件故障。
