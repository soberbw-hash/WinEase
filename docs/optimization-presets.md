# 一键优化配置组

2026-10-12：优化设置默认折叠，首页移除「先检查，再确认优化」说明。系统工具不再展示性能、存储、通知和隐私的跳转卡片；设备、默认应用、恢复等非二元管理操作保留为紧凑按钮。

## 行为

16 组实际配置统一读取。开表示目标配置已符合优化组，关表示尚未完整符合；未能核实显示错误并禁止执行。首次优化前保存原值、类型或缺失状态；关闭开关恢复该记录。已经由其他工具配置、且没有 WinEase 原记录时，无法推断更早的历史：界面明确提示关闭使用默认方案，首次观察值另行保留。电源回到平衡计划、磁盘维护恢复启用，注册表组使用定义的非优化值；之后反复开关沿用保存的基线，不会卡在开启状态。

首页检查会默认选择可读取且未完成的优化组，已完成的只展示。检查不修改系统；确认优化后只执行有效计划所选项。需要管理员权限的配置组合并为一次 UAC 请求，按组记录成功/失败。某组失败不掩盖其他结果；组内写入失败尝试回退本次变更，原配置记录保留。资源管理器相关配置在保存后自动刷新；部分应用配置在应用下次启动或重新登录后生效。

手动改配置后旧建议必须重新检查。应用卸载、个人文件和破坏性网络重置沿用原来的确认规则，不因配置默认建议而自动选中。

## 配置范围

| 组 | 开启的实际效果 |
| --- | --- |
| 关闭广告与推荐 | 关闭 Windows 推荐应用安装、系统技巧推广、部分推荐订阅、资源管理器同步推广、广告标识及诊断个性化。不是浏览器或所有第三方广告拦截器。 |
| 关闭可选诊断与反馈 | 诊断政策设为当前 Windows 版本允许的最低级别；关闭反馈通知。企业/教育类可设置 0，普通版本保留必须诊断级别 1。不删除安全日志、不禁用防护。 |
| 关闭应用通知 | 关闭应用横幅通知，可能错过消息；不会停用防护或结束应用。 |
| 启用游戏模式 | 同时设置 AllowAutoGameMode 与 AutoGameModeEnabled；不修改计时器、安全或内存策略。 |
| 关闭游戏录制 | 关闭后台录制、游戏捕获与 Game DVR 策略；独立截图组件保留。 |
| 关闭更新共享上传 | DODownloadMode=0，关闭电脑间共享，保留官方 HTTP 下载；不禁用更新服务。 |
| 启用安全自动清理 | 通过 Windows 存储感知策略每周处理未使用的临时文件；下载、回收站和云内容阈值为 0，禁止该自动清理处理这些个人内容。家庭版不支持该策略时明确禁用此项。 |
| 暂停自动磁盘优化 | 停用固定 ScheduledDefrag 任务，关闭时恢复原启用状态。不会执行磁盘整理，后续整理/TRIM 须手动处理。 |
| 高性能 | 优先使用本机已存在的卓越性能，其次标准高性能；不修改现代待机配置、不强行创建计划。关闭恢复首次保存的电源计划。 |
| 搜索仅显示本地内容 | 设置 DisableSearchBoxSuggestions，自动刷新资源管理器。 |
| 关闭移动设备自动播放 | 设置 DisableAutoplay，下一次插入设备使用新配置。 |
| 关闭活动历史上传 | 关闭 PublishUserActivities 与 UploadUserActivities，不停用本地剪贴板历史。 |
| 关闭输入个性化收集 | 关闭 TIPC、键入/手写个性化及通讯录训练数据收集。 |
| 关闭在线语音识别 | 关闭 HasAccepted 授权，需要联网的语音输入不可用。 |
| 关闭 Edge 后台驻留 | 关闭 StartupBoostEnabled 与 BackgroundModeEnabled。 |
| 减少 Edge 推广 | 关闭 ShowRecommendationsEnabled 与 PersonalizationReportingEnabled；效果受浏览器版本和账号类型影响。 |

设备加入组织域或检测到实际 MDM 管理证据时，机器级组停止操作。Windows 普通内置 EnrollmentState 记录本身不等于 MDM。读取管理状态失败时保守处理。配置组 ID、注册表位置、计划任务与执行命令固定，恢复文件必须匹配原配置结构；界面不能传入新命令、路径或任务名称。

## 验证

- 88 项 Rust 回归通过，13 项集成检查默认忽略。新增覆盖固定 ID/批量操作拒绝、独立项目任务锁、自动清理个人内容保护、隔离注册表原值与缺失值恢复、无历史首次关闭、组内失败回退、模拟电源/磁盘任务的合并执行和恢复。
- 本机 11 组只读配置成功返回，九类首页扫描成功完成；未执行实际优化、修改电源或停用计划任务。文件结果有数量/时间边界，不代表全盘精确核算。
- 浏览器 IPC 验证默认折叠、删除说明、11 个开关、键盘与恢复、失败状态、任务独立、默认建议、确认取消、旧建议失效及 1280/760 宽度布局。另回归首页、应用管理与系统修复流程。
- TypeScript/Vite、原生签名安装包用于本地预览，正式发布和不同设备原生管理员操作仍须单独验收。
