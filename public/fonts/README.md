# 内置鸿蒙字体

WinEase 界面使用 HarmonyOS Sans SC。字体随应用打包，通过本地 `@font-face` 加载，离线可用，首次运行无需另行安装。

来源：[华为设计资源](https://developer.huawei.com/consumer/cn/design/resource/)，[官方原始字体包](https://developer.huawei.com/images/download/general/HarmonyOS-Sans.zip)。

Regular、Medium、Bold 三个 TTF 文件从官方包按字节复制，未裁剪、子集化或转换格式；文件校验值见 `source.json`。`LICENSE.txt` 保留官方原始许可和版权声明，`LICENSE-readable.txt` 是去除原文件末尾空字节的阅读副本，许可文本内容相同。
